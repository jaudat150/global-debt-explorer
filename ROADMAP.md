# Roadmap

Ideas are tracked as GitHub issues; items marked **good first issue** are ideal for new contributors.

## Next
- Full spending-by-function (COFOG) layer via the free DBnomics API (IMF GFS COFOG + Eurostat `gov_10a_exp`).
- Side-by-side comparison of up to four countries.
- Time slider on the atlas (animate an indicator through the years).
- Shareable URLs (`?view=atlas&indicator=gov_debt_gdp&country=KEN`).
- **good first issue:** Arabic, French and Spanish interface labels.
- **good first issue:** more sourced entries for `LOCAL_FALLBACK_DB` (e.g. Venezuela, Lebanon arrears).

## Later
- Chinese official lending layer (AidData, BU Global Development Policy Center).
- IMF debt-distress ratings from published Debt Sustainability Analyses.
- Public JSON/CSV download endpoint refreshed weekly by GitHub Actions.
- Dark mode with validated colour steps.
